# User Greeting Program

## Description
This project is an interactive Python program.  
It is a simple application that asks the user for their name.  
The program is designed to demonstrate basic programming concepts.

## How it works
1. The program defines a function called greet_user.
2. The function receives the user's name.
3. It creates a message using the name.
4. The program asks the user to enter their name.
5. It checks if the input is empty.
6. The program prints a message based on the condition.
